# Qualified suppliers before underground conversion

These are the exact three supplier strings, manifest, native report and test
controller that preceded the two reviewed underground-belt rewrites. The
engine supplier remains selected with the same blueprint and original proof.

`pairing-report.json` records native underground mates and actual belt components
connected to read-all readers, using `pairing-control.lua`. The native graph uses
both belt-neighbour directions and underground mates. Its per-build blueprint
SHA-256 must match the original string before its component IDs may be used.

`feeders.mjs` is a restoration snapshot for its original script directory.
`construction-metrics.json` distinguishes placed entities from the iron needed
to craft red surface belts and underground endpoints. None of these numbers
claims a smaller bounding rectangle or lower operating ingredient demand.
