# Autosaved Science production continuation

This directory records the 17 Autosaved `Science` / `Production` entries after the five-candidate pilot. [coverage.json](coverage.json) reports per-source completion and remaining work: **5 validated source IDs, 12 pending**. `evidence.json` provides **each** catalogue source ID, exact source and candidate blueprint-string SHA-256, native-size bounding area and delta, preserved recipe-machine capacity per minute, entity counts, and current route/native status. The original catalogue strings remain unchanged. Run `node scripts/generate-core-production-batch.mjs` to reproduce these candidate strings.

The bounded transformation removes efficiency-module requests, labs and roboports, trims the right lab wing where it does not contain recipe machines, and drops now-unpaired underground endpoints. It preserves every original recipe machine. The candidates are experiments; the trimming step has not yet established complete material routing. `native-placement.json` records an exact-hash Factorio 2.1.24 import and revival of every entity and recipe for all 17. Placement does **not** prove ingredient flow or delivered production. The catalogue and recipe basis is Factorio 2.0.77 with Space Age; production at that pinned version remains to be tested.

V4 uses **one copper and one iron west belt entry**, retains the original copper splitter, and has a connected east output terminal. The exact source was run at identical exterior feed coordinates and injection cadence for each pair; in the v4 pair it delivered 72 automation and 25.2 logistic/min because its original pickup inserters and lab loads limit this fixture. Thus v4 demonstrates candidate capacity under the same offered input, but its source result is not a source-at-capacity baseline. V2 remains the accepted 600-tile matched-measured version; v4 is a validated higher-throughput experiment with 20 more footprint tiles. The failed one-copper splitter trial and its exact hash are retained in v3 evidence.
